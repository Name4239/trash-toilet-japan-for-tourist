# คู่มือที่ใช้กับโปรเจกต์ปัจจุบัน

คู่มือต่อจากนี้ให้ยึดโค้ดจริงใน `BackEnd` ไม่ยึดตัวอย่างเก่าที่ใช้ CommonJS หรือ Prisma 6

## รูปแบบโค้ดปัจจุบัน

- Node.js แบบ ES Module เพราะ `package.json` มี `"type": "module"`
- ใช้ `import` / `export` เท่านั้น ไม่ใช้ `require()`
- Express 5
- Prisma 7 และ generated client อยู่ที่ `generated/prisma`
- Database ใช้ MariaDB ผ่าน `@prisma/adapter-mariadb`
- ใช้ Zod ตรวจ Body, Params และ Query ก่อนเข้า Controller
- โหลด `.env` ด้วย `import "dotenv/config"`
- Server ใช้ `process.env.PORT` และ fallback เป็น `5000` แต่ `.env` ปัจจุบันกำหนด `3000`
- React Frontend เรียก Backend ได้ผ่าน CORS โดยค่าเริ่มต้นใช้ `http://localhost:5173`

## คำสั่งใช้งาน

รัน Backend ระหว่างพัฒนา:

```powershell
cd BackEnd
npm run dev
```

รันแบบปกติ:

```powershell
npm start
```

สร้าง Prisma Client ใหม่หลังแก้ schema:

```powershell
npx prisma generate
```

ตรวจสอบ schema:

```powershell
npx prisma validate
```

สร้าง migration:

```powershell
npx prisma migrate dev --name ชื่อ_migration
```

เปิด Prisma Studio:

```powershell
npx prisma studio
```

## ข้อสำคัญก่อนทำต่อ

โปรเจกต์นี้ตกลงใช้ MariaDB แล้ว:

- `schema.prisma` ใช้ `provider = "mysql"`
- `src/lib/prisma.js` ใช้ `PrismaMariaDb`
- package ใช้ `@prisma/adapter-mariadb`

ไม่ต้องเปลี่ยนเป็น PostgreSQL ในขั้นตอนถัดไป

`src/app.js` ไม่มีอยู่ในโปรเจกต์ เพราะ Express app และจุดเริ่ม Server รวมอยู่ใน `src/server.js`

## ลำดับการทำงานปัจจุบัน

```text
Frontend/Postman
→ server.js
→ routes
→ auth/admin middleware
→ Multer ถ้า Request มีรูป
→ Zod validation
→ controller
→ Prisma
→ MariaDB
```

อ่านต่อที่ [ลำดับอ่านโค้ด Backend](03-ลำดับอ่านโค้ด-Backend.md)

## ระบบรูปปัจจุบัน

- `POST /api/places` รับ `multipart/form-data` field `image`
- `PATCH /api/users/me/avatar` รับ field `avatar`
- `POST /api/reports` รับ field `evidence`
- รูป Report เป็นหลักฐานชั่วคราวและลบเมื่อ Admin จัดการเสร็จ
- Login ปัจจุบันใช้ Email/Password ไม่มี Google Login
